# Cipher Engine
A C++ file encryption and decryption system using XOR-based transformations, feedback chaining, binary file handling, and operator overloading.

## Features
- XOR-based encryption and decryption
- Feedback chaining
- Binary file processing
- Chunk-based data handling
- Custom operator overloading (`<<` and `>>`)
- Key validation

## Technologies
- C++
- STL
- File Streams

## Usage
1. Compile and run the program.
2. Select encryption or decryption.
3. Enter the input filename.
4. Enter a valid encryption key.
5. Find the processed output in the generated file.

## Disclaimer
This project is intended for educational purposes. Its custom XOR algorithm is not suitable for securing sensitive data in production.
